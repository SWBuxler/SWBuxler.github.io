Eight directions for the same site

Same content, same structure, eight visual worlds. Every sample below is a live render of the real hero and project row — not a screenshot — so what you're comparing is only the design.

Copy is placeholder where facts are still missing. The name and the five-year framing are real; anything in [ brackets ] is waiting on Seth. Judge the type, color, and spacing — not the words.
01

How I'd narrow it

All eight are buildable in about the same time — the structure doesn't change, only site.css. So pick on fit, not effort.

  1. Safest pair: 03 or 06. Swiss reads fast and prints clean; Trading Desk borrows the visual language of the software he actually built, which quietly reinforces the whole pitch.
  2. If the write-ups carry the site: 01 or 07. Both reward reading. Worth it only if the project pages are genuinely strong.
  3. Highest ceiling, highest variance: 08. The only direction nobody else applying will have. It works if he stays in ag/commodities and falls flat if he doesn't.
  4. I'd move off 05. It's what's built now, and it's fine — but warm cream with a terracotta accent has become the house style of AI-generated portfolios. A reviewer who's seen a few will place it instantly.

Tell me a number — or a hybrid, like 03's grid with 06's palette — and I'll rebuild the stylesheet. The HTML doesn't change.
