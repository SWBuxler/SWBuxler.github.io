Nobody assigned me this.

When I started coding at age 8, I didn't know it would become my passion - it was just a fun hobby. And even after I started to consider programming as a career path, the main reason I kept programming was for the simple love of the game.

scroll

02 · the hobby becomes a job

I was shipping production code before I could vote.

In 2021, I found a job as a programmer - not an internship or a temporary position, an actual job with responsibilities where the code I created would actually end up being used. This was when I first entered the workforce - and I did it before I turned 18.

03 · a crisis point?

But if AI can do the same thing as me, why bother?

It's a valid concern for many in the software industry. AI is fast. It's good at doing many of the things software engineers have done in the past. And it's getting smarter by the day.

04 · an inflection point

It won't replace me. It'll just help me code better.

The LLM wave hit in the middle of my professional career to date. As a result, I've had access to the best of both worlds: the value of coding by hand and the intimate knowledge of a codebase that comes from it, and the unmatched speed and power of LLM coding tools. I've survived the AI boom, and I understand how to leverage the tools it gave us - how to use them to write boilerplate, well-understood code with careful oversight, while building the cutting edge by hand. AI won't end my career as a software developer - it will enhance it.
